# credit-card-friction-analysis
SQL, Excel, and Tableau analysis of CFPB credit card complaints with a break even business case
Status: In progress

Business question
Which credit card complaint issues cause the most customer friction, and which fix would pay for itself?

What will be in this repo
sql: data profiling, cleaning, and analysis queries
excel: statistical tests and the business case model
dashboard: screenshots and a link to the live dashboard
docs: memo, deck, and framing notes
